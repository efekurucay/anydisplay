WINDOWS SETUP

An Android second screen
for your Windows PC.

AnyDisplay can stream a Windows monitor to an Android phone or tablet. Mirror first, or add the optional Virtual Display Driver for a separate extended workspace.

Before you start

The Windows host is experimental. It runs on Windows 10 version 1809 or later and Windows 11, on x64 PCs. Android requires version 8.0 or later. Download the APK and Windows ZIP from the downloads section.

One community report confirms a successful USB connection and 2200×1440 hardware HEVC stream with a TCL NXTPAPER 11 Plus on Windows 11. Input injection, audio, clipboard and other GPU combinations still need more device testing. Start with a short connection test before making this part of your daily setup.

1. Open the Android app and Windows terminal

Install the APK on Android and leave AnyDisplay open. Extract the Windows ZIP, then open PowerShell in the folder that contains anydisplay-win.exe. 

.\anydisplay-win.exe list

The list command reports available monitors, USB devices, Wi-Fi clients and stored pairings. The Windows host currently uses the command line; there is no desktop setup wizard.

2. Connect through USB or Wi-Fi

USB

Install Android Platform-Tools and make sure adb is available in your terminal. Enable Android Developer options and USB debugging, use a data cable, unlock the device and accept the computer authorization prompt. 

adb devices -l
.\anydisplay-win.exe usb

The adb device state must be device. If several devices are attached, provide the serial shown by adb: 

.\anydisplay-win.exe usb YOUR_DEVICE_SERIAL

Devices with an empty serial are supported starting with v0.1.1. For a device listed as (no serial number), leave only one USB Android device connected and use the plain usb command.

Wi-Fi

Put the PC and Android device on the same local network. Replace the example IP with the one shown by the Android app: 

.\anydisplay-win.exe connect 192.168.1.20

Compare the pairing code on both screens, confirm in the terminal and accept it on Android. If a connection fails, check firewall rules and wireless client isolation. The app listens on TCP port 47820; internet-facing port forwarding is not needed.

3. Choose mirroring or an extended desktop

Mirroring shows an existing monitor on Android. AnyDisplay can do this without a separate display driver.

Extending gives Windows another monitor to place windows on. For this, install the optional open-source Virtual Display Driver. It is a separate project, not bundled with AnyDisplay. Follow the driver setup instructions and configure a mode matching the tablet’s resolution.

Arrange the extra monitor in Settings → System → Display. Run list again; AnyDisplay marks the recognized driver monitor as [Virtual Display Driver] and selects it by default. If needed, use --monitor N with the monitor number from that list.

Common Windows connection problems

No authorized USB device
Unlock Android, accept its USB debugging prompt and retry adb devices -l. A charging-only cable will not work.
The connection is found but streaming never starts
Leave AnyDisplay open on Android. Capture the host error with -v and include it in a bug report.
The tablet mirrors instead of extending
Check that Virtual Display Driver is installed and recognized. Without it, mirroring is expected.
Touch does not control an elevated Windows app
Windows restricts input from a normal process into administrator windows. See the host documentation before changing how you run it.

Help expand the tested-device list

The serial-less USB fix came from a real device report and contributor PR. If your setup works, report the Android model and version, Windows version, connection type and which features you tried. If it fails, include the error text, without pairing secrets or unrelated personal information.

Send a device report, or compare other Android second-monitor apps. Mac users can follow the macOS guide.
