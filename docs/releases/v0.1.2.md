## Pen and touch fixes

- Fix Windows pen and touch coordinates when monitors sit to the left of or above the primary display (#4).
- Keep Android stylus strokes active when a finger touches or leaves the screen (#5).
- With palm rejection disabled, update and cancel both finger and pen input in mixed gestures, preventing stuck touch contacts and unintended trackpad clicks.
- Add seven Android input routing regression tests and five Windows coordinate regression tests.

Thanks to @Floop3 for both contributions!

### Downloads

Install the APK on Android and the matching host on your computer. The Mac app supports Apple
silicon and Intel (macOS 14+); it is ad-hoc signed and not notarized. Windows 10/11 support remains
experimental. USB needs Android Platform-Tools and USB debugging; Wi-Fi does not.

[Setup guide](https://efekurucay.com/anydisplay/#setup) ·
[Source and known limitations](https://github.com/efekurucay/anydisplay#status)
