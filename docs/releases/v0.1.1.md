## USB fixes and an easier first connection

- Detect Android devices that report an empty USB serial on Windows and macOS.
- Explicitly target USB for serial-less devices, avoiding an unrelated `ANDROID_SERIAL` setting.
- Add macOS discovery regression tests and clearer USB authorization guidance.
- Add Setup & Troubleshooting to the Mac menu bar app.
- Add a landing page, step-by-step setup guide and a tested-device table.
- Document the first community Windows hardware report: TCL NXTPAPER 11 Plus, hardware HEVC at 2200×1440.

Thanks to @dionisvl for the Windows fix, tests and device report in #3!

### Downloads

Install the APK on Android and the matching host on your computer. The Mac app supports Apple
silicon and Intel (macOS 14+); it is ad-hoc signed and not notarized. Windows 10/11 support remains
experimental. USB needs Android Platform-Tools and USB debugging; Wi-Fi does not.

[Setup guide](https://efekurucay.github.io/anydisplay/#setup) ·
[Source and known limitations](https://github.com/efekurucay/anydisplay#status)
