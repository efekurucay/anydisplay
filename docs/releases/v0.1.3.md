## Older tablets show video again

- Fix "Waiting for video…" on devices whose hardware decoder holds several frames before its first
  output, such as the Samsung Galaxy Note 10.1 (GT-N8000, Exynos 4 `OMX.SEC.AVC.Decoder`). The
  host stopped at its 3-frame flow-control limit before the decoder showed anything.
- Android: once a frame stays inside the decoder for 500 ms, frames are acknowledged when queued.
  Other decoders behave as before.
- macOS and Windows hosts: 100 ms after the screen stops changing, the last capture is encoded
  again up to 8 times, so a static screen reaches decoders that wait for more input.
- The protocol document describes both rules under flow control.

### Downloads

Install the APK on Android and the matching host on your computer. The Mac app supports Apple
silicon and Intel (macOS 14+); it is ad-hoc signed and not notarized, so after updating, turn
Screen Recording and Accessibility off and on again for AnyDisplay. Windows 10/11 support remains
experimental. USB needs Android Platform-Tools and USB debugging; Wi-Fi does not.

[Setup guide](https://efekurucay.com/anydisplay/#setup) ·
